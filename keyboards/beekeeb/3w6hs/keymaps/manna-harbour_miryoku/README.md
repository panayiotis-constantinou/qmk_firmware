# 3w6hs Miryoku

Miryoku on the beekeeb 3w6hs (split 3x5+3). The keymap, the personal Nav, Mouse, and Num layers, OS-aware clipboard keys, and the mouse jiggler all come from [users/manna-harbour_miryoku](../../../../../users/manna-harbour_miryoku/). The board has no LEDs and no Herdr layer.

```
qmk compile -kb beekeeb/3w6hs -km manna-harbour_miryoku
```

Flash the resulting `.uf2` by copying it to the RP2040 boot drive.
