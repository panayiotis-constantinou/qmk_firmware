# Moonlander Miryoku

The Herdr MIDI control layer is shared with the Planck EZ Miryoku keymap. See the [shared layer diagram](../../../../../users/manna-harbour_miryoku/readme.org#herdr-midi-control-layer).

Moonlander-specific behavior:

- Controls use Miryoku's 36 keys; the other keys stay dark while a Miryoku layer's colors show.
- The left's spare column beside the index finger shows the four agent slots, top to bottom.
- The right's spare key beside K shows the host connection, and the right's innermost number-row key shows the sort mode: dim green for Herdr's Priority panel order, dim peach for Grouped.
- Caps Lock, Scroll Lock, and the mouse jiggler show on spare keys on both halves.
- The small LEDs stay dark; they no longer show layers 1-3.
- Layer colors only show in solid color mode. If an effect is running, Media + B restores them.
